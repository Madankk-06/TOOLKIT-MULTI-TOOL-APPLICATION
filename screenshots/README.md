# 📸 Application Screenshots Directory

This folder is dedicated to holding screenshots for the repository's main `README.md`.

---

### 📂 Recommended Filenames

Save your application screenshots directly into this directory with the following filenames:

1. **`smartsearch.png`** — Screenshot of SmartSearch AI query routing in action.
2. **`multitool.png`** — Screenshot of the Split-Screen Multi-Tool Workspace view (`/multi-tool`).
3. **`analog_clock.png`** — Screenshot of the 3D Holographic Analog Clock page.
4. **`color_picker.png`** — Screenshot of the Particulate Color Picker canvas.
5. **`insights.png`** — Screenshot of the Mady AI Insights dashboard (`/insights`).

---

### 📐 Recommended Specs
- **Format**: PNG or WebP
- **Resolution**: 1920×1080 (1080p) or 1280×720 (720p)
- **Ratio**: 16:9 widescreen
- **Quality**: Sharp, crisp text with dark/light mode showcased.

---

Once you place the images here, run:
```bash
git add screenshots/
git commit -m "Add project screenshots"
git push origin main
```
Your main GitHub `README.md` will automatically display the screenshots!
